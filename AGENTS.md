# Project guide for coding agents

Prototype rebuild of a Vietnamese e-commerce + blog site (thucduongthienan.com, currently on the
LoveItop SaaS) to evaluate a tech migration. Local use only. Human-facing docs: `README.md` (Vietnamese).
Reply to the user in Vietnamese unless they write in another language.

## Stack

- Next.js **16.4** App Router, React 19, TypeScript, Tailwind CSS 4 (via `@tailwindcss/turbopack`).
- Database: **`node:sqlite`** (built into Node ≥ 22.13; use Node 24, see `.nvmrc`). No ORM, no native modules.
  Do not add `better-sqlite3`/Prisma unless asked - a C++ toolchain may not exist on the user's machine.
- `cacheComponents` is intentionally **off**; pages are server-rendered on demand.

## Commands

| Task | Command |
|---|---|
| Install | `npm install` |
| Dev server | `npm run dev` → http://localhost:3000 (run it in the background; it does not exit) |
| Type-check | `npm run typecheck` (runs `next typegen` then `tsc --noEmit`) |
| Production build | `npm run build` then `npm start` |
| Import an article from the live site | `npm run import:post -- <https://thucduongthienan.com/<section>/<category>/<slug>.html>` |
| Reset DB to seed data | stop the server, delete `data/`, start again (imported posts are lost) |

There is no test suite. Verify changes with `npm run typecheck`, `npm run build`, and `curl` against the
dev server (expect 200 for valid pages, 404 for unknown slugs).

```
  page.tsx                   home: one product block per category + latest posts
  san-pham/[category]/[product]/page.tsx   product detail; param ends with ".html"

  [section]/[slug]/page.tsx  /thuc-duong/<cat>/ OR /chinh-sach/<x>.html OR /<cat>/<post>.html
  [section]/[slug]/[post]/page.tsx  canonical post URL /<section>/<cat>/<post>.html
  cart/, checkout/, checkout/thankyou/
  api/v2/add-to-cart/[id], api/data-checkout, api/v2/province(/ward)   JSON route handlers
  add-to-cart/[id], search/post/autocomplete, load-comment, submit-comment
components/                  Header (server), SearchBox/AddToCart/Comments/CheckoutForm (client), ui.tsx
lib/db.ts                    DB singleton (globalThis), SCHEMA, migrate(), helpers all/one/run
lib/seed.ts                  placeholder seed, runs when product_categories is empty

```

## Conventions and gotchas

- **URLs must match the original site.** Build links only through `url.*` in `lib/data.ts`.
  Listing URLs end with `/`; detail URLs end with `.html`; `/cart`, `/checkout` and JSON endpoints have no slash.
  `next.config.ts` sets `trailingSlash: true` + `skipTrailingSlashRedirect: true` to allow this - keep both.
- `params` / `searchParams` are Promises: `const { slug } = await params`. Type them with the global helpers
  `PageProps<"/route">`, `LayoutProps<"/route">`, `RouteContext<"/route">` (generated by `next typegen`).
- Page files may only export Next.js page fields; put shared components in `components/`.
- `cookies()` is async and can only be **set** in route handlers or server actions, not in pages.
- DB rows from `node:sqlite` have a null prototype; the `all`/`one` helpers spread them into plain objects so
  they can be passed to Client Components. Use those helpers instead of raw `prepare()` in app code.
- The DB connection is cached on `globalThis`. After changing `SCHEMA`/`migrate()`, **restart the dev server**
  or you will see errors like `no such column`. Schema changes must be additive and handled in `migrate()`
  (existing `data/shop.db` files must keep working); mirror column additions in `scripts/import-post.mjs`.
- Imported article HTML comes from the old CKEditor and is rendered with `dangerouslySetInnerHTML` inside
  `.prose-content` (styles in `app/globals.css`). It is trusted content from the owner's own site.
- `ExperimentalWarning: SQLite is an experimental feature` in logs is expected.

## Admin (`/admin/`)

- Email + password accounts in SQLite (`admins`, `admin_sessions`; scrypt hashing in `lib/auth.ts`). The first visit to `/admin/`
  shows a "create first admin" form; once an admin exists it is a login form.
- CRUD for products and posts via Server Actions in `app/admin/actions.ts` (every action calls `requireAdmin()` - keep that).
  Admin pages (all under the sidebar layout `app/admin/layout.tsx`, a full-screen layer over the shop header/footer):
  dashboard `/admin/`, `products/` + `products/[id]`, `posts/` + `posts/[id]` (`id` = number or `new`), `orders/` + `orders/[id]`
  + `orders/export` (CSV), `comments/`, `pages/` + `pages/[key]` (key = `<grp or ->__<slug>`), `categories/`, `settings/`.
  Shared admin UI: `components/admin/ui.tsx`; admin queries: `lib/admin-data.ts`; brand settings editable in DB: `lib/settings.ts`
  (`getSite()` replaces importing `site` from `lib/site.ts` in server components).
- Orders have a `status` column (`new|confirmed|shipping|done|cancelled`, see `ORDER_STATUS`). Price `0` on a product means "Liên hệ" (no add-to-cart). Products have a `stock` column (default `100`; `0` means out of stock); placing an order deducts stock and cancelling an order restores it. New orders trigger an email notification (`lib/mail.ts`, SMTP config in `/admin/settings/`, default recipient `agvinh@gmail.com`).
- `npm run import:products [-- --replace|--limit N|<url>]` scrapes real products (sitemap + homepage + category pages) into the DB and
  `public/uploads/products/`. `--replace` deletes the placeholder sample products. Run inside Docker: `docker compose exec web npm run import:products`.
- Images are saved to `public/uploads/{products,posts}/` by `lib/uploads.ts`; `/admin/upload` is the route handler used by the
  post editor's "Chèn ảnh" button. `products.image` column added in `migrate()`. `serverActions.bodySizeLimit` is raised in `next.config.ts`.
- Runtime uploads into `public/` are only served by `next dev`, not by a pre-built `next start`.

## Reference: original site structure

- Platform: LoveItop template `base3`, server-rendered, jQuery 3.3.1 + Bootstrap 4.3.1.
- Article page: `article.article-detail` → `h1.post-detail-title`, `.post-detail-date` (dd/mm/yyyy),
  body in `.decription`; images are lazy-loaded with the real URL in `data-isrc` (images on `media.loveitopcdn.com`).
- Original endpoints also include `/api/v2/smart-feature-menu/load`, `/ajax_regen_captcha` and
  `/api/account/affiliate/...` (not implemented here).

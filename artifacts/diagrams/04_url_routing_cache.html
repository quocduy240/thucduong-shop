Sơ đồ Định tuyến URL Tương thích LoveItop & Kiến trúc Caching Đa tầng

Cơ chế ưu tiên phân giải đường dẫn App Router và luồng bộ nhớ đệm qua Browser, Edge KV, React cache() và D1

ROUTING & CACHING
1. Phân giải Định tuyến URL (Tương thích LoveItop) trailingSlash: true + skipTrailingSlashRedirect
Single Source of Truth (lib/data.ts -> url.*):
Danh sách kết thúc bằng / · Chi tiết kết thúc bằng .html · Cart/Checkout/API không có dấu gạch chéo bắt buộc (lưu ý POST cần trailing /).
Ưu tiên 1: Tuyến Tĩnh Tường minh (Static Segments)
/ (Home) · /san-pham/ · /canh-duong-sinh/ · /cart · /checkout · /search/ · /tu-van-nhanh/ · /thanh-vien/ · /tra-cuu-don-hang/ · /so-do-trang.html · /sitemap.xml · /robots.txt
Ưu tiên 2: Tuyến Động Chức năng & Theo dõi Chuyển hướng
/san-pham/[category]/ · /san-pham/[category]/[product].html · /ho-so-tu-van/[token]/ · /q/[slug] (tăng scans + 302) · /go/social/[id] (đếm clicks + UTM + 302)
Ưu tiên 3: Bộ phân giải 1 Cấp app/[section]/page.tsx
Kết thúc .html -> getPage('', slug) (VD: /gioi-thieu.html).
Ngược lại -> getPostSection(section); riêng /thu-vien/ hiển thị <VideoLibrary />.
Ưu tiên 4: Bộ phân giải 2 Cấp app/[section]/[slug]/page.tsx
Có .html: Ưu tiên getPage(first, slug) (/chinh-sach/*.html) trước, sau đó fallback getPost(first, slug) (URL bài viết ngắn).
Không .html: /thu-vien/tai-lieu-thuc-duong/ -> <DocumentLibrary />, /thu-vien/bai-giang-thuc-duong/ -> Trigger YouTube Sync + <VideoLibrary />.
Ưu tiên 5: Tuyến Chuẩn Canonical 3 Cấp [section]/[slug]/[post]
URL chuẩn /<section>/<category>/<slug>.html: xuất JSON-LD Article, canonical URL, OpenGraph và nhúng <ArticleReadTracker /> cộng +2 điểm Loyalty.
Tất cả 22 Public/Webhook API routes (/api/v2/*, /api/data-checkout, /load-comment...) giữ nguyên đường dẫn tương thích LoveItop.
2. Kiến trúc Caching Đa tầng & Vô hiệu hóa Theo Tag Regional KV TTL 300s
Tầng 1: HTTP / Browser / CDN Cache Phản hồi theo loại tài nguyên
• /api/media/*: public, max-age=31536000, immutable (+ ETag 304 trên [slug])
• /uploads/*: 30 ngày + SWR 1 ngày · /sitemap.xml: 300s · /robots.txt: 3600s
• /api/v2/cart-summary, session-summary, health: no-store
Tầng 2: Client Memory & SessionStorage Cache Giảm gọi API lặp trên trình duyệt
• HeaderAccountCart: cache giỏ/tên thành viên 45 giây + gộp inflight.
• FrontendAdminProvider: cache ngữ cảnh Admin 180 giây trong sessionStorage.
• DocumentLibrary & ThemeSwitcher: lưu trạng thái tại localStorage.
Tầng 3: SSR Root Layout & React Request Cache Lưu ý hành vi force-dynamic thực tế
• app/layout.tsx đặt export const dynamic = 'force-dynamic' để luôn đọc Theme/Widget mới nhất, do đó vô hiệu hóa ISR cấp trang (revalidate = 60/300 ở trang con).
• React cache() khử trùng lặp truy vấn trùng trong cùng 1 request SSR.
Tầng 4: Next.js Data Cache (unstable_cache) + Cloudflare KV open-next.config.ts + lib/cache-tags.ts
• Lưu trên NEXT_INC_CACHE_KV kèm withRegionalCache (mode long-lived 300s).
• Đang cache: settings (60s), product_categories (60s), post_sections/categories (120s), pages (120s), videos/topics (120s), documents (120s).
• Truy vấn products/posts/blocks/flashSale hiện đọc trực tiếp D1 mỗi request.
Cơ chế Vô hiệu hóa: invalidateStorefront(...tags) 9 Tag tập trung trong lib/cache-tags.ts
Tags: site, categories, products, posts, pages, videos, documents, blocks, flashSale.
Khi Admin lưu dữ liệu -> gọi revalidateTag(tag, 'max') + revalidatePath('/', 'layout').
Ngoài ra quick_consult_cache trong D1 lưu kết quả AI Tư vấn nhanh theo SHA-256 trong 14 ngày.

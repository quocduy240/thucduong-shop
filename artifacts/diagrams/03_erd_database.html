Sơ đồ Thực thể Quan hệ Cơ sở Dữ liệu Cloudflare D1 (Database ERD)

Toàn bộ 48 bảng/thực thể (phát sinh từ baseline schema + ensure*Schema() + migrations/) phân theo 6 miền nghiệp vụ

D1 DATABASE ERD
1. Danh mục, Sản phẩm & Khuyến mãi (5 bảng)
product_categories 1 -> N products
PK id · slug (UQ) · name · sort · show_in_menu/home/footer · is_active · seo_title · description
products N -> 1 category
PK id · slug (UQ) · FK category_id · sku/kv_code/barcode · price/sale_price/cost_price · contact_only · stock/min/max · is_published · source_url · seo_*
comments N -> 1 product
PK id · FK product_id · name · content · rating (1..5) · created_at
flash_sale_slots & flash_sale_items 1:N slot · N:1 product
slots: PK id · start_hour · end_hour · discount_pct | items: FK slot_id · FK product_id · flash_price · quota · sold · gift_note
2. Nội dung, Thư viện & Marketing (10 bảng)
post_sections -> post_categories -> posts Phân cấp 3 tầng
sections(PK slug) · categories(PK id, FK section_slug) · posts(PK id, FK category_id, cover, source_url, related_product_ids, seo_*)
pages & content_blocks Block đệ quy
pages: PK (grp, slug) · title · content | content_blocks: PK id · slug · style_variant · positions · target_post/product_ids
videos & youtube_sync_pending 318+ videos
videos: PK id · video_id · topic · title · sort | pending: PK video_id · youtube_url · status (pending|approved)
documents & document_leads 1 -> N leads
documents: PK id · doc_type · folder_path · access_mode · bundle_product_id · downloads | leads: FK document_id · contact
qr_codes Shortlink /q/[slug]
PK id · slug (UQ) · target_url · fg/bg_color · positions · target_post/product_ids · scans · active
3. Đơn hàng, POS, Kho vận & Quỹ (9 bảng)
provinces & wards 1 -> N wards
provinces(PK code, name: 34) -> wards(PK code, FK province_code, name: 3.321)
orders & order_items 1 -> N items
orders: PK id · code (UQ) · phone · status (6 tt) · payment · coupon_code · shipping_* · kiotviet_order_id | items: FK order_id · product_id · price · qty
coupons Dùng tại Checkout
PK id · code (UQ) · type (percent|fixed) · value · min_order · max_discount · member_only · used_count · active
inventory_movements Thẻ kho lịch sử
PK id · product_id · change_qty · stock_after · unit_cost · reason (7 loại) · ref_code · created_by
cashbook_entries, suppliers & delivery_partners Sổ quỹ 3 Quỹ
cashbook: entry_type (in|out) · payment_method (cash|bank|kiotviet) · amount | suppliers (5+) · delivery_partners (6+)
4. Quản trị, Thành viên, CRM & Loyalty (15 bảng)
admins & admin_sessions RBAC 7 ngày
admins: PK id · email (UQ) · phone (UQ) · role (4 cấp) · salt/hash | sessions: PK token · FK admin_id · expires_at
members & member_sessions Auth 30 ngày
members: PK id · email (UQ) · phone · tier · points | member_sessions: PK token · FK member_id · expires_at
member_profiles & point_transactions Sổ cái Hợp nhất
profiles: PK id · user_id · current/lifetime_points · tier · status · merged_into_id · referral_code · total_orders/spent | tx: FK member_id · source (14) · ref_type/id
point_rules, reward_catalog, reward_redemptions Đổi quà Atomic
rules: code · points_formula | catalog: type · points_cost · stock · min_tier | redemptions: FK member_id · FK reward_id · coupon_code · fulfillment_status
referrals, daily_login_streaks & newsletter Gamification
referrals: referrer_id · referee_id · status | streaks: member_id · current/best_streak | newsletter_subscribers: email · status
crm_notes, crm_customer_tags & crm_automation_logs RFM +3/+25 ngày
notes: customer_key · next_followup_date · followup_done | tags: (customer_key, tag) | logs: (order_id, step_code)
5. Hệ sinh thái AI, Tư vấn & Import (6 bảng)
quick_consultations Hồ sơ /ho-so-tu-van/
PK id · customer_name · phone · audience · height_cm · weight_kg · needs/conditions/habits/diet_recall_json · article_html · share_token · expert_report_html · booking_*
quick_consult_cache Cache AI 14 ngày
PK cache_key (SHA-256) · article_html · hit_count · created_at
lab_analyses Worker hồi phục 3p
PK id · patient_name · file_mime · file_base64 (xóa khi done) · raw_text · status · summary · analysis_html · started_at
post_import_jobs Lease lock 40s
PK id · source_url · extra_urls · status (7 tt) · step_cursor · locked_until (40s) · research_json · policy_audit_json · draft_json · post_id
product_import_jobs Lease lock 35s
PK id · source_url · product_id · status (7 tt) · step_cursor · locked_until (35s) · raw_payload · normalized_payload · working_images
consultation_requests Widget Hỏi nhanh
PK id · name · phone · question · page_url · status (new|done)
6. Cấu hình Hệ thống, Media & Chỉ mục (3 bảng + Indexes)
settings (Key-Value JSON & Config Store) 15+ nhóm cấu hình
PK key · value | Lưu: Brand/SMTP/Widget, gemini_api_key, ai_motifs_json, medical_compliance_policy, expert_consult_config, kiotviet_*, flash_sale_*, social_links_config, ui_themes_config, sitemap_config, youtube_sync_config, invoice_print_config_json
media_files (r2-storage fallback) Phục vụ /api/media/[...path]
PK path · mime · data_base64 · created_at
media_assets (media-assets fallback) Phục vụ /api/media/[slug]
PK slug · mime_type · data_base64 · created_at
